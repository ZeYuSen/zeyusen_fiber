# 玻璃纤维短切毡与方格布：按工艺、载荷和表面要求选型

玻璃纤维短切毡（CSM）和方格布解决的是不同的层压问题。短切毡把短切纤维分布在多个面内方向，并用粘结剂保持片材完整；方格布则把连续玻纤束交织在通常为经向和纬向的两个织物方向上。两种结构都不是天然“更好”，只看 GSM 也不能判断哪一种应进入部件。

真正有用的选择往往不是简单二选一，而是判断应使用**短切毡、方格布、两者组合，还是两者都不选**。判断前需要依次核对载荷路径、模具几何、树脂与成型工艺、表面要求，以及具体产品的证据。本文帮助生产、工程和采购团队完成初选并形成可比的询价条件；最终铺层仍须经过工程设计与工艺验证。

## 决策表：短切毡、方格布、两者组合或其他结构

| 决策输入 | 短切毡可作为候选的情况 | 方格布可作为候选的情况 | 应考虑其他结构的情况 |
|---|---|---|---|
| 铺层作用 | 需要分散覆盖、服帖的过渡层或一般增厚 | 需要沿经纬方向布置连续纤维 | 主要任务是表面控制、单向承载或偏轴剪切承载 |
| 载荷路径 | 载荷不由单一明确方向主导 | 主要载荷能与两个织物轴线对齐 | 需要单向或 ±45° 增强 |
| 几何形状 | 材料须服帖于复合曲面和过渡区，并通过铺覆试验 | 区域较宽、平坦或只有缓曲，且织物能够贴合 | 小圆角、深凹位或剧烈过渡仍会造成架空或织物变形 |
| 树脂与工艺 | 具体粘结剂和上浆剂已确认适配树脂及成型工艺 | 上浆、织物稳定性、浸透与压实特性适配工艺 | 工艺需要缝编导流结构、喷射纱、预浸料或其他专用形式 |
| 可见表面 | 经验证后可作为背衬或过渡层 | 应避开不能接受织纹透出的表面 | 首要任务是外观或防腐蚀屏障；应评估表面毡或薄毡 |
| 放行证据 | 有 TDS、粘结剂/上浆说明、卷材数据和代表性试样 | 有 TDS、结构、方向、上浆、卷材数据和代表性试样 | 供应商无法确认产品化学体系，或试样未达到验收标准 |

该表只用于筛选，不是铺层设计。某种材料可能通过一项检查，却在另一项检查中被否决。

## 为什么不应先问“哪一种更强”

方格布沿织物轴线保持连续纤维束；短切毡则把较短的纤维分布在多个方向。这种结构差异会改变玻纤在铺层中的位置，但单凭这一点不能确定成品部件的强度。

要进行有效比较，至少应在相同的层压基准下记录：

- 玻璃类型和准确的增强材料牌号；
- 单位面积质量、层数、方向和成品厚度；
- 树脂、上浆或粘结剂兼容性、固化制度和成型工艺；
- 纤维含量、孔隙、搭接、接缝和缺陷；
- 试样方向、状态调节和测试方法。

如果缺少这些控制条件，“方格布更强”或“短切毡各方向强度相同”只能作为纤维结构的宽泛描述，不能当作部件性能数据。图纸或规格中有力学要求时，应比较经过确认的层压板数据，或测试有代表性的试样，而不是只按两个干态卷材的 GSM 下结论。

## 第一道门：先定义铺层作用和载荷方向

先看这一层要做什么，再看材料名称。

- **分散覆盖或服帖过渡：** 当粘结剂、上浆和操作行为适配工艺时，短切毡可以作为候选。
- **双向增强：** 当经纬方向能与预期载荷路径对齐时，方格布可以作为候选。
- **单一主载荷方向：** 应评估[单向增强材料](/zh/博客/unidirectional-vs-woven-fiberglass-guide)，不要为了使用熟悉的品类而强行指定双向织物。
- **偏轴或剪切主导载荷：** 应评估具有所需角度的[双轴或多轴向织物](/zh/博客/multiaxial-fiberglass-fabric-for-composites)。
- **外观或防腐蚀表面：** 应评估[表面毡或薄毡](/zh/博客/fiberglass-surface-tissue-for-composite-finish)。短切毡不是同一种产品，也不应作为名称上的替代品。

这一关可以避免常见的采购错误：设计真正需要的纤维方向并不在两个熟悉的目录品类中，却仍被迫二选一。

## 第二道门：让具体牌号匹配树脂和工艺

“短切毡适合聚酯，但不适合环氧”不能作为通用规则。粘结剂化学体系取决于具体产品。例如，3B 的 EM 1011 数据表明确把一种乳液粘结短切毡列为适用于聚酯、乙烯基酯和环氧体系；另一些短切毡围绕苯乙烯可溶粘结剂设计，在环氧体系中可能无法正常工作。方格布同样需要核对：其上浆必须适配树脂，浸透和织物稳定性也必须适合成型工艺。

批准前，应针对准确牌号取得书面答案：

1. 使用什么上浆剂？短切毡使用什么粘结剂？
2. 已确认适配哪些树脂类别和具体树脂产品？
3. 产品面向手糊、模压、灌注、RTM、连续层压还是其他工艺？
4. 数据表是否说明该工艺下的浸透、排气、抗冲刷、压实或表面表现？
5. 代表性浸润与固化试验是否达到项目验收条件？

当前制造商产品系列说明了这一步的重要性。Owens Corning 为开模、闭模、层压、浸透和表面目标提供多个短切毡牌号；Jushi 也列出具有不同加工特性的短切毡和方格布产品代码。品类名称适合用于检索，真正控制采购的是牌号和相应证据。

可用[增强材料上浆与树脂兼容性指南](/zh/博客/reinforcement-sizing-resin-compatibility-guide)把这一关转换为询价字段。

## 第三道门：在真实几何上试铺、检查架空和操作性

随机短切纤维通常比厚重的平纹方格布更容易跟随复合曲面，但这不等于可以直接放行。粘结剂含量、克重、纤维分布、织法、卷材状态、裁切、搭接和操作方法都会改变实际铺覆表现。

小试应选择部件最难处理的特征，而不只是在平板试样上进行。需要记录：

- 干态增强材料能否保持贴合于转角和凹位；
- 哪些位置需要开剪口、裁切、搭接或增加过渡层；
- 铺放时纤维束是否变形、毡是否分离、边缘是否掉屑；
- 树脂能否在工艺窗口内完全浸透该层；
- 固化后是否仍有困气、架空、褶皱、干区或织纹透出。

如果任何一种材料在关键特征处失败，应调整裁剪方案、克重、结构或整体铺层。不能把泛化的“高服帖性”宣传当成模具适用证据。

## 第四道门：有目的地安排每一层

在一些接触成型层压结构中，短切毡和方格布经常组合使用：短切毡可以形成过渡或分散层，方格布则沿两个轴线提供连续纤维。但这只是一种可选铺层，不能推导出“每两层方格布之间都必须夹短切毡”。

应从功能出发决定每一层：

1. 明确可见面或工艺面，判断是否需要胶衣、表面薄毡或其他表层。
2. 按设计要求把结构纤维放到正确方向。
3. 只有在能解决明确的界面、操作或增厚问题时，才添加过渡或分散增强层。
4. 核对所有相邻层与树脂、固化和成型顺序的兼容性。
5. 对完整铺层验证厚度、纤维含量、缺陷、表面以及所需力学结果。

规划完整结构时，可参阅[复合材料铺层结构指南](/zh/博客/composite-laminate-layers-surface-structural-core)。在某些工艺中，缝编复合毡可减少分层铺放步骤；多轴向或单向结构也可能更有效地布置承载纤维。这些都应进入候选，而不是最后才考虑。

## 四个决策示例（并非预设铺层）

| 场景 | 初步筛选结论 | 仍须验证的内容 |
|---|---|---|
| 大面积壳体、接触成型、载荷路径明确为 0°/90° | 方格布作为结构层候选；仅在需要过渡或分散层时加入兼容短切毡 | 铺层表、树脂/上浆/粘结剂、浸透、排气、厚度和结构测试基准 |
| 复合曲面模压罩壳，可见面受控 | 表面毡或薄毡用于表面；兼容短切毡可作为背衬候选 | 表面小试、织纹透出、转角、固化和独立结构增强层 |
| 复杂特征处的环氧修补 | 不采购泛称短切毡；根据载荷选择明确适配环氧的毡或其他结构 | 牌号级粘结剂/上浆证据、修补设计、粘接前处理和代表性固化试验 |
| 以 ±45° 剪切载荷为主的灌注板 | 短切毡和 0°/90° 方格布都不是自动答案；评估 ±45° 多轴向结构 | 渗透性、压实、树脂流动、纤维方向和实测层压性能 |

这些示例只展示决策逻辑，不构成船体、储罐、板材或修补设计。

## 询价与试样记录

拟定铺层中的每一种增强材料单独填写一行：

| 字段 | 应说明的内容 |
|---|---|
| 铺层作用 | 表面、过渡、分散增强、结构或其他明确功能 |
| 结构 | 短切毡、方格布、单向、多轴向、表面毡或复合毡 |
| 纤维与克重 | 玻璃类型、标称 g/m² 和允许偏差；不要只写 GSM |
| 方向 | 适用时写明经纬方向或所需铺层角度 |
| 化学体系 | 上浆、粘结剂类型和书面树脂兼容性 |
| 树脂与工艺 | 树脂类别/牌号、手糊或闭模工艺及相关工艺条件 |
| 几何与表面 | 困难圆角、凹位、搭接规则、可见面和织纹透出限制 |
| 供货形式 | 幅宽、卷长/卷重、纸管、包装、接头和追溯要求 |
| 证据 | 当前 TDS、证书字段、变更控制要求和所需测试报告 |
| 试样验收 | 浸透、操作、固化缺陷、厚度、表面和项目专用测试条件 |

未知字段标为**请供应商提案**，不要猜测。确认后把条目转入[复合材料增强材料询价清单](/zh/博客/composite-reinforcement-rfq-checklist)。

## FAQ

### 方格布一定比短切毡更强吗？

没有统一的层压与测试基准，就无法作出通用比较。方格布沿织物轴线布置连续纤维束，短切毡则把较短的纤维分布在多个方向。成品强度还受树脂、纤维含量、厚度、方向、孔隙、固化和测试方向影响。实际设计应使用经确认的层压数据。

### 短切毡可以与环氧树脂一起使用吗？

有些产品可以，有些不可以。决定因素是准确的粘结剂和上浆体系，而不是品类名称。应取得明确写出环氧兼容性的当前数据表或供应商声明，再用计划使用的环氧进行浸润与固化验证。

### 每两层方格布之间都应放短切毡吗？

不能默认如此。在一些接触成型铺层中，短切毡过渡层可能有用，但每一层都应有明确作用。正确顺序取决于树脂、工艺、界面、厚度、表面和结构要求，应验证完整铺层，而不是照搬通用交替模式。

### 同一 GSM 的短切毡和方格布可以直接比较吗？

不可以。相同单位面积质量不代表结构等效。纤维长度与方向、织法、粘结剂或上浆、树脂用量、纤维含量、成品厚度和缺陷都可能不同。GSM 只是询价字段之一，不是选型结论。
