# 碳纤维布规格指南：采购询价应写清哪些参数

“碳纤维布”不是完整的采购规格。两款织物即使外观相似，也可能在纤维等级、丝束、织纹、面密度、幅宽、上浆体系、卷装和树脂工艺适用性上不同。字段缺失时，供应商只能自行假设，收到的报价也可能不是同一种产品基础。

本指南把笼统需求转换为可审核、可比较的规格，主要适用于干态编织增强材料。预浸料、单向带、编织套管和多轴向非屈曲织物还需要额外字段。

## 最低规格字段

| 字段 | 应写明什么 | 为什么重要 |
|---|---|---|
| 纤维 | 等级或性能依据；必要时注明批准来源 | 明确增强材料输入和比较基础 |
| 丝束 | 如有要求，注明3K、6K或12K等规格 | 影响纱线尺寸、纹理尺度、操作和织物结构 |
| 织纹 | 平纹、2x2斜纹、缎纹或其他明确组织 | 影响稳定性、铺覆、表面纹理和屈曲 |
| 面密度 | 标称g/m²及受控时的公差 | 表示单位面积纤维质量，不等于固化厚度 |
| 幅宽 | 最小可用宽度及允许公差 | 影响排版、接缝、裁切利用率和设备匹配 |
| 上浆 / 表面 | 树脂兼容要求或已批准上浆体系 | 影响操作和纤维-树脂界面 |
| 工艺 | 手糊、灌注、预浸料转化、模压或其他 | 便于供应商检查操作和工艺适配性 |
| 树脂 | 树脂家族和已知限制 | 用于筛查上浆、粘结和浸润匹配 |
| 外观 | 检查面、织纹、颜色、污染和缺陷限制 | 把“外观级”转换为可检验条件 |
| 卷装与包装 | 卷长或卷重、纸管、接头、标签和防潮 | 避免收货与生产环节出现偏差 |
| 文件 | 按需列出TDS、批次数据、证书、追溯或报告 | 让质量和合规范围进入同一报价 |

并非所有项目都要严格控制每一项。关键是把字段标为“必须”“优选”“允许供应商建议”或“不适用”。

## 1. 明确纤维，但不要无目的地过度指定

如果工程图纸要求特定等级，应直接写明。如果项目采用性能要求，应列出性能、试验方法和验收依据，而不是脱离上下文复制某个品牌牌号。同时说明是否允许等效等级，以及审核等效方案需要哪些资料。

当前产品目录把[碳纤维斜纹布](/carbon-fiber/carbon-fiber-cloth/twill-cloth)和[碳纤维平纹布](/carbon-fiber/carbon-fiber-cloth/plain-cloth)列为200 g/m²、T300产品。这可以作为目录筛选起点，但具体应用批准仍需当前产品资料和项目自己的层合验证。

## 2. 丝束规格只有在真正影响要求时才锁定

丝束标记表示一束碳纤维中大致的单丝数量：3K约为3,000根，6K约为6,000根，12K约为12,000根。采购方常用丝束控制织物纹理尺度和结构，但丝束本身不能定义成品织物性能。

当丝束会影响外观、织纹几何、操作、后续设备或已批准设计时，应明确写入。如果没有强制要求，可以要求供应商说明拟用丝束，再结合完整织物数据审核。

## 3. 根据几何和操作选择织纹

平纹交织点较多，通常具有较稳定的织物结构。2x2斜纹呈对角纹理，在部分曲面上更容易铺覆。正确选择取决于模具几何、裁片尺寸、铺放操作、外观要求和铺层方案。

不要假定一种织纹能贴合所有复合曲面，应在实际模具上进行工艺试验。现有[斜纹与平纹碳布指南](/blog/carbon-fiber-cloth-twill-plain-weave-guide)提供了更细的操作对比，但通用说明不能替代真实试铺。

## 4. 不要把GSM当作厚度

面密度表示单位面积中的纤维质量。固化层合板厚度还取决于纤维密度、织纹、树脂含量、压实、孔隙和铺层数量。“200 GSM、1 mm厚”的需求并不完整，除非说明1 mm指单层干布、固化层合板还是成品部件。

采购规格应写标称GSM和允许公差。层合设计则应另行定义铺层数量、固化厚度目标，以及需要控制时的纤维体积分数或树脂含量和试验方法。

若你也用 oz/yd² 计量，[玻璃纤维织物克重指南](/blog/fiberglass-fabric-weight-gsm-oz-conversion-guide) 说明了 GSM 与 oz/yd² 的换算以及面密度不能确定的内容。

## 5. 说明最小可用幅宽和卷装

应写明最小可用幅宽，而不只写织机或标称宽度。还可包括边缘处理、允许的边缘变形、纸管尺寸、卷长或卷重、设备允许的最大外径，以及是否允许接头。若计划自动裁切，应提供排版宽度和方向限制。

这些细节经常决定一份单价较低的报价能否真正进入生产。

## 6. 匹配上浆体系、树脂和工艺

向供应商说明树脂家族和生产方式。如果已有批准的上浆体系，应明确标识；如果尚未确定，应要求供应商说明所用上浆剂及其目标树脂兼容性。没有相应数据时，不应把干态织物描述成“兼容所有树脂”。

有用的工艺信息包括：

- 开模还是闭模；
- 手工铺放还是自动操作；
- 灌注路径和预计流动方向；
- 常温还是加热加工；
- 是否会转制为预浸料；
- 表面、孔隙和外观验收要求。

## 7. 把外观要求转换为验收标准

对可见碳纤维部件而言，“外观好”过于主观。应明确检查哪一面、织纹对齐、最大弓纬或斜纬、允许的缝隙、断丝束、毛丝、污染、色差、边缘状态，以及一卷材料中允许标记缺陷的比例。如需颜色匹配，应在规定光源下批准实体限度样。

对于内部结构层，可能不需要严格的外观限制，但污染、损伤、宽度、克重和追溯仍可能重要。

## 8. 报价前列清文件要求

文件要求会影响价格、准备时间和供应商资格评估，因此应在RFQ中列出。可能包括技术数据表、适用时的安全资料、分析或符合性证书、批次追溯、试验报告、限用物质声明、装箱单字段和原产地信息。

只要求项目会真正审核的文件。通用文件清单过长，可能增加成本却不能改善质量控制。

## 报价对比检查

比较价格前，确认每份方案采用相同单位、可用幅宽、克重公差、卷装基础、包装、文件范围和交付条件，并标出所有供应商偏离项。如果报价没有说明丝束、上浆、公差或接头政策，就还不能与字段完整的方案直接比较。

如果增强材料家族仍未确定，可先使用[碳纤维与玻璃纤维选型指南](/blog/carbon-fiber-vs-fiberglass-selection-guide)。确定织物后，把完整字段转入[复合材料增强材料询价清单](/blog/composite-reinforcement-rfq-checklist)，并通过[联系页面](/contact)提交。

如果丝束规格尚未确定，请先阅读[3K、6K 与 12K 碳纤维丝束指南](/blog/carbon-fiber-tow-size-3k-6k-12k-guide)，再比较供应商报价。

## FAQ

### 如果图纸指定的等级不在供应商目录里，可以要求提供等效产品吗？

通常可以，但前提是询价中说明是否允许等效方案，以及审核所需的证据。应要求供应商提供拟用等效材料的性能依据、试验方法和支持数据，而不是仅凭品牌名称，这样才能与指定等级在同一基础上比较。

### 应索要哪些资料来确认织物符合规定的GSM和力学性能依据？

应索取技术数据表，以及与所规定标称面密度和公差对应的批次试验数据。如果力学性能是要求的一部分，应确认采用的试验方法，并核实其是否符合公认方法，例如[ASTM International standards](https://www.astm.org)发布的标准，这样不同供应商的数据才能进行比较。

### 为什么两份看起来是“同一种”碳纤维布的报价，价格会相差很大？

外观相似的织物报价出现差异，往往是因为可用幅宽、克重公差、卷长或接头政策、外观验收和所需文件等字段没有明确说明。除非所有报价都在同一基础上写明这些字段，否则价格差异可能反映的是范围不同，而不是真实的成本差距。
