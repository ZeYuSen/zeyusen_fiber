# 碳纤维丝束规格指南：3K、6K 与 12K 怎么选

3K、6K、12K 描述的是一束碳纤维中大约包含多少根连续单丝。它们本身不能说明纤维牌号、织纹、面密度、幅宽、上浆体系、层合板厚度或成品性能。

因此，“需要 3K 碳纤维布”仍不是完整采购规格。本指南解释 K 数在编织碳布规格中的位置，并给出可用于比较供应商报价的字段，避免把某一种丝束大小当作普遍更优的等级。

## 快速理解 3K、6K 与 12K

| 丝束标识 | 每束约含单丝数 | 可以帮助说明 | 不能单独确定 |
|---|---:|---|---|
| 3K | 3,000 | 纱束大小与外观尺度 | 纤维牌号、克重、织纹、幅宽、上浆与层合性能 |
| 6K | 6,000 | 纱束大小与织物结构输入 | 固化厚度、强度、浸润和表面质量 |
| 12K | 12,000 | 纱束大小与生产结构输入 | 织物是否适合某种工艺或部件 |

K 数只是规格字段之一，不是性能排名。相同 3K 标识的两款织物，其他采购字段仍可能完全不同。

## 单丝、丝束、经纱和纬纱

**单丝**是单根连续碳纤维，**丝束**是许多单丝并在一起形成的纱束。织造时，丝束作为纱线输入，按织物结构分别布置在长度方向的**经向**和横向的**纬向**。

碳纤维制造商 Toray 将 tow 定义为卷绕在筒管上的一组碳纤维单丝，并使用 K 表示单丝数量级。该定义能支持基本术语，但采购仍需取得具体织物结构和产品数据。

## 丝束大小如何影响织物结构

丝束变大或变小，会改变织造可使用的纱束输入，但成品还取决于经纬密度、织纹、张力、展纱、面密度和后处理。

采购时应检查这些具体结果：

- **纹理尺度：**丝束大小与纱线间距共同决定可见织纹大小。
- **覆盖程度：**织物是否开孔不能只看 K 数，还要看经纬密度和结构。
- **面密度：**不同丝束和间距组合可能得到相近或不同的 g/m2。
- **操作性：**稳定性、铺覆、毛边和变形由完整织物结构决定。
- **树脂作用：**上浆、展纱、织纹和工艺条件都会影响浸润表现。

外观或操作性重要时，应索取实物样品。照片和 K 数不能代替卷材验收。

## K 数不能说明哪些关键事项

### 纤维牌号

丝束大小不等于拉伸等级、模量、制造商或批准的等效牌号。请单独写明目标牌号或性能依据，不要假设所有 3K 纤维具有相同原丝和性能。

### 织纹

平纹、斜纹、缎纹及其他组织都可能使用不同丝束。织纹必须独立写明；如果织纹还未确定，可先阅读[碳纤维布平纹与斜纹指南](/blog/carbon-fiber-cloth-twill-plain-weave-guide)。

### 面密度

GSM 是单位面积干态增强材料的质量，K 数并不包含这个信息。请写明标称 g/m2，以及设计或质量计划真正控制的公差。

### 固化厚度

干布厚度与固化层合板厚度不是同一个量。固化厚度还受铺层、纤维体积分数、压实、树脂、工艺和测量方法影响，不能把丝束标识直接换算成单层厚度。

### 树脂相容性

供应商应说明上浆或相容性依据。K 数相同并不证明产品一定适用于环氧、乙烯基酯、聚酯、酚醛或其他基体。

## 用相同字段比较供应商方案

报价前先建立对照表：

| 字段 | 方案 A | 方案 B | 买方决策 |
|---|---|---|---|
| 纤维制造商与牌号 | | | 指定或批准等效 |
| 丝束 | | | 3K、6K、12K 或其他明确数量 |
| 经纬结构 | | | 经纬是否同一丝束，是否混杂 |
| 织纹 | | | 平纹、斜纹、缎纹或指定结构 |
| 标称 GSM 与公差 | | | 项目控制范围 |
| 可用幅宽与公差 | | | 与裁切排版匹配 |
| 上浆与树脂依据 | | | 对照实际基体确认 |
| 卷长与接头规则 | | | 操作与利用率要求 |
| 检验与文件 | | | 数据表、批次、CoA 或约定报告 |
| 样品批准 | | | 留样与验收条件 |

存在空白字段时，两份报价可能不是同一种材料基础，价格也就不能直接比较。

## 什么时候考察 3K、6K 或 12K

- 当项目需要较细的可见纹理或已有结构明确指定时，考察 **3K**。
- 当批准的织物结构或现有供应链要求该纱束输入时，考察 **6K**。
- 当较宽丝束属于目标织物结构或生产路线时，考察 **12K**。
- 如果真实要求是克重、幅宽、操作性、表面或层合性能，应保持丝束选择开放，让供应商按完整条件提出方案。

最终选择应由织物结构、供应商数据、代表性工艺和部件验证共同支持。

## 样品批准应对应采购规格

1. 核对样品标签、纤维牌号和丝束是否与要求一致。
2. 记录织纹、GSM、幅宽、表面、边缘与卷装状态。
3. 在代表性几何上执行实际裁切、铺覆、浸润与固化工艺。
4. 按项目验收方法评价层合板或部件。
5. 后续批次需要对比时，保留批准样或客观参考数据。

结构或工艺重要时，不能只批准外观；操作和表面重要时，也不能只批准一张数据表。

## FAQ

### K 数越高，织物就越强吗？

不是。K 数只表示一束丝束中大约包含多少根单丝，并不代表纤维的拉伸等级、模量或成品层合板的强度。12K 织物不会自动比 3K 织物更强，强度取决于纤维牌号、织纹、GSM、纤维体积分数、树脂体系和工艺，这些都需要单独写明。

### 丝束大小能决定织物的 GSM 或织纹吗？

不能。丝束大小只是织物结构的一个输入条件，GSM（面密度）和织纹由织造方的纱线间距、经纬密度和后处理独立决定。相同 K 数的两款织物仍可能有不同的 GSM 和织纹，因此规格或询价单中需要分别列出这两个字段。

### 询价单中应如何写明丝束大小？

在询价单中，将丝束（3K、6K、12K 或其他）与纤维牌号、经纬结构、织纹、标称 GSM 及公差、幅宽、上浆依据和所需文件一并列出。仅列出丝束大小会让产品定义的其余部分保持开放，因此应把它当作完整规格中的一个字段，而不是独立的标识。
