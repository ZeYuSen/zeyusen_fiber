# 除湿转轮成型纸怎么选：基材规格与采购询样指南

向供应商询价“除湿转轮用纸”时，先说清楚要买的是原纸、已经处理的蜂窝芯材，还是成品转轮。这三种采购范围对应不同的报价内容和验收证据，不能放在一起比较。

泽宇森的[除湿转轮成型纸](/glass-fiber/tissue-mat/rotor-paper)属于湿法玻璃纤维原纸，以卷材供下游加工。具体规格需要结合压楞、粘接、浸渍或涂覆工艺评价。仅凭原纸规格，不能认定成品转轮能够达到某个除湿量或露点。

如果询盘涉及的是能量回收，而不是已经明确的除湿项目，可先阅读[除湿转轮原纸与全热交换转轮介质的用途区别](/blog/desiccant-rotor-paper-vs-enthalpy-wheel-media)，确认设备任务与采购范围。

## 先分清采购的是哪一层材料

| 采购对象 | 实际评价的内容 | 应索取的证据 |
| --- | --- | --- |
| 玻璃纤维基材原纸 | 用于平层和瓦楞层的载体 | 纸张牌号、尺寸、粘结剂信息及约定的材料检测结果 |
| 经过处理的蜂窝芯材 | 成型结构与选定吸附剂体系的组合 | 加工记录、孔道几何及约定的芯材级测试 |
| 成品除湿转轮 | 在指定运行条件下工作的完整转轮 | 转轮级性能数据、测试条件和机械接口要求 |

例如，[SORPS 的转轮资料介绍了平层与瓦楞玻纤纸交替组成的结构](https://www.sorpstech.com/solutions/desiccant-rotor-manufacturer)。这有助于理解材料层级，但不能作为泽宇森原纸兼容性或成品性能的证明。

询价时也应写清责任分工：原纸供应商确认供货内容及可提供的材料数据；转轮制造方定义加工路线，并验证最终产品。传给原纸供应商的成品指标，应标为应用目标，避免被理解为未经加工的原纸已经具备该性能。

## 把应用要求写成可比较的纸张规格

下面是一份采购沟通表，不是强制标准。已有依据的字段填写目标和允许范围，尚未确定的字段标为待讨论。供应商提供数值时，还应说明它是典型值还是保证值，以及使用什么方法测得。

| 项目 | 询价时写什么 | 还要确认什么 |
| --- | --- | --- |
| 材料与供货阶段 | 湿法玻纤原纸，是否包含后处理 | 准确牌号和处理状态 |
| 克重 | 目标值、允许偏差，单位 g/m² | 取样位置、调湿条件与检测方法 |
| 厚度 | 目标值、公差和单位 | 测量压力及试样状态 |
| 卷材形式 | 幅宽、纸芯尺寸、最大卷径或卷长、收卷方向 | 设备匹配、接头要求与包装方式 |
| 加工强度 | 纸幅在哪些位置受到牵引、折弯或支撑 | 对应条件下的纵向、横向数据 |
| 湿法加工 | 浸渍或涂覆体系、工序顺序 | 与原纸粘结剂的兼容性和试样方法 |
| 成型几何 | 用于平层还是瓦楞层，目标楞形 | 楞形、裂纹和粘接的试样验收条件 |
| 使用工况 | 转轮用途与计划运行范围 | 哪些项目必须在处理后的芯材或成品转轮上验证 |

两份报价标着相同的克重，并不代表材料等同。一份只提供未注明条件的典型厚度，另一份提供了约定方法下的验收范围，这两份文件回答的就不是同一个问题。先统一口径，再比较价格。

## 白色外观不能代替牌号和测试

![白色泽宇森玻璃纤维纸张，展示纸面纤维纹理和叠放边缘](/images/glass-fiber/01-fiberglass-tissue-mat/04-rotor-paper/desiccant-rotor-forming-paper-white-sheets.jpg)

图中是白色纸张的产品实拍，能够展示供货形态，不能说明粘结剂成分、湿态强度、耐温上限或吸附能力。判断具体材料时，应对应样品标签和规格文件，不能把颜色当成牌号。

比较[玻璃纤维表面毡](/glass-fiber/tissue-mat/surface-tissue)与转轮成型纸时也是如此。它们都属于[玻纤毡与薄毡系列](/glass-fiber/tissue-mat)，但面向不同加工用途。用于复合材料表面的薄毡，即使外观或名义克重相近，也不能直接替代转轮用纸；需要针对实际成型和处理路线取得证据。

## 说明加工路线，不要只写吸附剂名称

“用于硅胶转轮”或“用于分子筛转轮”能够说明应用方向，却还不足以确定原纸规格。应补充哪些工序在成型前进行，哪些在成型后进行，纸张在哪些阶段处于湿态，以及已经确定的粘结剂或涂覆要求。涉及配方细节时，通过合适的保密流程沟通。

不同路线对纸张的处理顺序可能不同。[CN117599588A 公开了一种使用平层和瓦楞玻纤纸制备蜂窝芯材的方案](https://patents.google.com/patent/CN117599588A/zh)。它是具体工艺实例，不是通用生产配方，也不表示泽宇森采用该方法。

在订购生产用料前，先约定自己的加工路线中每个阶段检查什么。可使用[压楞与蜂窝试样验证清单](/blog/desiccant-rotor-paper-corrugation-trial-checklist)，分开记录原纸和加工后试样的观察结果。

## 让不同供应商的报价真正可比

采购与工程可以共用下面这份简短记录，避免“已经报价”被误认为“已经确认适用”。

| 决策项目 | 每个候选材料分别记录 |
| --- | --- |
| 身份信息 | 供应商、牌号、规格文件版本和样品卷号 |
| 报价范围 | 原纸处理状态、尺寸、数量、包装和要求的文件 |
| 已确认要求 | 每个约定项目的数值、单位、方法和公差 |
| 未确认要求 | 缺少的信息、负责人和下一步 |
| 试样决定 | 进入评价、等待证据，或不适合本次试样条件 |
| 生产决定 | 完成约定验证后，另行记录生产批准依据 |

例如，两家都能提供所需幅宽，但只有一家确认了纸芯尺寸，那么另一份报价还不能完成上机匹配审查。这只是文件比较的示例，不是客户案例或实测结果。

试样批准和生产批准要分别记录。询样文件应让供应商能够准备有用的评价卷材，同时把尚未验证的要求保留下来。数量、交付和文件等商业字段，可以结合[复合材料采购询价清单](/blog/composite-reinforcement-rfq-checklist)整理。

## 采购常见问题

### 除湿转轮成型纸本身就是吸附剂吗？

不能这样理解。先确认报价对象是原纸、处理后的芯材，还是成品转轮。泽宇森产品页描述的是供下游加工的玻纤基材，并未把成品转轮的除湿性能作为原纸参数。

### 选择更高克重是不是更稳妥？

克重不能单独决定适用性，还要结合厚度、纸幅受力、楞形和处理路线。是否采用某个规格，应由约定的试样证据支持，不能只比较报价单上的数字大小。

### 同一款纸换一种吸附剂还能直接用吗？

需要记录变更，并审查新工艺的兼容性。某一组原纸、粘结剂、处理方式和设备条件下的认可，不能自动沿用到另一组组合。

### 厚度或粘结剂要求还没有确定，能询样吗？

可以先说明应用和加工限制，把未确定字段列出来，请供应商讨论起始评价规格。不要为了填满表格而自行猜测验收限值。
