# 复合材料增强材料询价清单：碳纤维与玻纤采购RFQ

一份有效的询价单不只是写出材料名称。它应让供应商有足够信息识别正确的增强材料、暴露假设、采用一致的商业口径报价，并在样品或量产订单前指出技术缺口。

本清单适用于干态碳纤维和玻璃纤维增强材料，包括编织布、多轴向织物、短切毡、表面薄毡、纱线、短切纤维和粉状材料。只填写与产品有关的字段；对未知项写“请供应商建议”，不要凭空猜测。

## 1. 从部件和应用开始

简要说明要制造什么，以及增强材料承担什么任务：

- 部件或产品名称；
- 行业和最终用途；
- 结构、表面、外观、导电、绝缘或工艺作用；
- 相关时说明温度、化学品、湿度、紫外或阻燃环境；
- 关键尺寸和表面要求；
- 失效后果，以及是否属于法规或客户控制用途。

首次沟通不一定要披露机密几何。经过脱敏的图纸、截面草图、层合概念或照片也能帮助说明任务。需要详细设计数据时，应使用合适的保密流程。

## 2. 确定增强材料形式

选择最接近的形式，或明确请求供应商提案：

| 增强材料形式 | 常见RFQ字段 |
|---|---|
| 编织碳布或玻纤布 | 纤维、丝束 / 纱线、织纹、GSM、幅宽、上浆、卷装、外观限制 |
| 单向或多轴向织物 | 纤维、方向、各层克重、缝线、总GSM、幅宽和工艺 |
| 短切毡 | 玻璃类型、GSM、需要时的纤维长度、粘结剂、幅宽和树脂工艺 |
| 表面薄毡 | 纤维、GSM、粘结剂、幅宽、颜色 / 表面作用和树脂体系 |
| 方格布 | 玻璃类型、织纹、GSM、幅宽、卷装和树脂工艺 |
| 碳纤维纱线 | 等级、丝束、上浆、包装重量和缠绕 / 编织用途 |
| 短切或粉状碳纤维 | 原料纤维、标称长度或分布、上浆 / 表面、包装形态和树脂用途 |

可通过[碳纤维产品目录](/carbon-fiber)和[玻璃纤维产品目录](/glass-fiber)确定初步形式，但不要只根据产品图片选型，仍需确认规格和工艺适配性。

## 3. 写明材料规格

列出使产品可识别、可检验的字段：

- 纤维家族和等级，或性能依据；
- 结构：织纹、随机毡、定向铺层、缝编或薄毡；
- 标称面密度和公差；
- 相关时的丝束、纱线、纤维长度或铺层方向；
- 可用幅宽和公差；
- 上浆剂、粘结剂或表面处理；
- 可见材料的颜色和检查面；
- 允许缺陷和抽样方法；
- 等效方案审批规则。

编织碳布可使用[碳纤维布规格指南](/blog/carbon-fiber-fabric-specification-guide)。如果碳纤维还是玻璃纤维尚未确定，先用[材料选型指南](/blog/carbon-fiber-vs-fiberglass-selection-guide)明确部件真正关心的取舍。

## 4. 说明树脂和制造工艺

增强材料不能脱离加工过程选择。应向供应商提供：

- 树脂家族和已确定的具体体系；
- 手糊、喷射、灌注、RTM、模压、缠绕、预浸料转化或其他工艺；
- 开模还是闭模；
- 常温还是加热加工；
- 铺覆、流动、预成型或自动操作要求；
- 是否控制表面、印纹、孔隙或纤维移动。

如果兼容性尚未建立，应询问所用上浆或粘结体系，以及供应商能提供哪些依据，并使用真实树脂和模具安排工艺试验。

## 5. 用可比较的单位给出数量

同时说明试制需求和已知的重复采购需求：

- 样品或试制数量；
- 首批生产订单数量；
- 预计月度或年度需求，并明确这是估算；
- 采购单位：平方米、千克、卷、包或件；
- 可接受的卷长或包装重量；
- 是否接受非整卷或卷内接头。

不要只问“你们的MOQ是多少”。更有效的问题是：在指定结构、包装、文件和试制数量下，供应商能否提供，以及采用什么商业基础。预测数量不能写成保证订单。

## 6. 区分期望日期和已确认交期

提供交付目的地、已选定时的贸易术语、期望到货日期，以及样品或批准节点。要求供应商说明生产周期、可用运输基础、报价有效期和排期假设。

期望日期只是输入，不是供应商承诺。最终确认的时间应绑定完整规格、数量、文件包、付款条件和批准状态。

## 7. 定义包装和标签

包装会影响防潮、搬运、仓储适配和追溯。相关时可写明：

- 纸管尺寸和卷材方向；
- 最大卷重或外径；
- 袋、膜、纸箱、托盘或木箱要求；
- 防潮层或干燥剂；
- 托盘尺寸和堆码限制；
- 产品、批次、卷号、重量、长度、日期和采购单号等标签字段；
- 条码或客户标签格式；
- 接头和缺陷标记方式。

## 8. 只索取真正需要的文件

列出准确的质量与合规文件。根据项目不同，可能包括：

- 技术数据表；
- 适用时的安全资料；
- 分析或符合性证书；
- 批次和卷号追溯；
- 试验报告和试验方法；
- 限用物质或法规声明；
- 原产地和海关信息；
- 装箱单和标签样稿；
- 变更通知要求。

说明文件是报价时、批准前还是每批发货时提供，并写清语言和文件格式。

## 9. 定义样品与批准步骤

向供应商说明候选材料如何获批。常见顺序可以包括文件审核、材料样品、进料检验、工艺试验、试板或试片、原型件，以及首件或量产批准。明确每一步的责任人和通过条件。

结构用途不能只凭一小块外观样品批准。批准方法应与材料作用和失效后果匹配。

## 发送前最终检查

- 每一个数字字段都带单位。
- “必须”“优选”和“可选”要求已分开。
- 报价单位和数量基础明确。
- 已提供树脂和制造工艺。
- 包装、文件和目的地已计入商业范围。
- 未知技术字段写明“请供应商建议”，没有自行编造。
- 验收和样品步骤与失效后果匹配。
- 机密文件通过适当的受控渠道共享。

完成清单后，可通过[联系页面](/contact)提交。清楚的RFQ可以更早暴露技术偏离，也能让采购团队在一致基础上比较方案。

## FAQ

### 如果还不知道某个技术字段（比如GSM或树脂体系）怎么办？

请标注“请供应商建议”，不要凭空猜一个数值。猜测的数值可能会被直接按字面报价和生产，事后修正比留出开放字段要困难得多。

### 第一份RFQ到底需要写到多详细？

只要足以识别部件、其作用和增强材料形式即可，即使还有多个字段未定也没关系。第一份RFQ不需要把所有规格都定死；已知的字段要写清楚，未知的字段要标注为待定，而不是留空或凭空假设。

### 为什么要把必须项和优选、可选项分开？

供应商会根据哪些是硬性要求、哪些可以协商来制定不同的报价方式。如果所有字段都写成硬性要求，供应商就无法提出成本更低的等效方案或可行的替代建议，报价也可能因此排除了本可以满足实际需求的选项。
