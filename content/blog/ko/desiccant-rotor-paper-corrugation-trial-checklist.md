# 제습 로터용 원지 시험 체크리스트: 파형 성형·함침·허니컴 시편 기록

유용한 원지 시험 기록은 다른 엔지니어가 작업을 이어받을 수 있어야 합니다. 어느 롤을 사용했는지, 어떤 공정 버전을 적용했는지, 변화가 처음 관찰된 단계는 어디인지, 다음 작업은 누가 결정했는지를 확인할 수 있어야 합니다. 완성된 허니컴 시편만 보관해서는 이런 질문에 모두 답하기 어렵습니다.

이 글은 자체 공정에서 [제습 로터용 유리섬유 원지](/glass-fiber/tissue-mat/rotor-paper)를 평가하는 로터 제조사를 위한 기록 제안입니다. 산업 표준이나 Zeyusen이 실시한 시험 보고서가 아닙니다. 실제 시험 방법과 합격 기준은 프로젝트의 기술·품질 담당자가 정해야 합니다.

사진은 원지의 외관을 보여 줍니다. 인장강도, 화학적 적합성 또는 성형 시험 합격을 입증하는 자료는 아닙니다.

## 원지 정보와 실제 공정 순서를 먼저 정리합니다

Zeyusen은 로터 코어의 평면층과 파형층에 쓰이는 습식 유리섬유 원지를 공급합니다. 각 시편을 제품 번호, 공급자 로트, 롤 번호와 연결하세요. 평면층과 파형층에 서로 다른 원지를 사용한다면 각각의 식별 정보를 기록합니다.

성형, 접합, 함침 또는 코팅, 그리고 적용되는 건조·처리 단계를 실제 순서대로 적습니다. 프로젝트에서 승인한 공정 경로를 따르세요. 이 체크리스트는 함침이 성형 전인지 후인지를 일률적으로 정하지 않습니다.

시험 시작 전에 공정 개정 번호와 시편 번호를 부여합니다. 원지 요구사항이 아직 정해지지 않았다면 [원지 선정 가이드](/blog/desiccant-rotor-substrate-paper-selection-guide)를 먼저 참고해 구매 시 확정할 조건과 시험으로 확인할 질문을 구분하세요.

## 단계별로 비교할 수 있는 자료를 남깁니다

아래 행은 실제 공정 순서에 맞춰 배열하고 필요한 단계를 추가하거나 제외하세요. 각 기록에는 시편 번호, 공정 조건 버전, 관찰 결과, 사진 또는 보관 시편 정보, 처리 결정을 연결합니다.

| 단계 | 기록할 항목 | 보관할 자료 |
| --- | --- | --- |
| 가공 전 평면 원지 | 롤 번호, 채취 위치, 원지 방향, 가장자리와 눈에 보이는 흔적 | 라벨 정보, 가공 전 사진, 식별된 미가공 원지 조각 |
| 파형 성형 | 금형·롤 또는 형상 번호, 조건 버전, 파형 상단·골·가장자리 관찰 결과 | 식별된 성형 시편과 균열·찢어짐·형상 불균일 부위 사진 |
| 함침 또는 코팅 | 처리 시스템 번호, 공정 버전, 처리 전후 관찰 결과 | 비교 가능한 전후 사진과 단계별 식별 시편 |
| 접합 및 허니컴 조립 | 평면층·파형층 원지 번호, 조립 버전, 접합부와 유로의 외관 | 시편 방향, 단면 사진, 접합 분리나 유로 막힘의 위치 |
| 정해진 처리와 상태 조절 후 | 방법 버전, 단위를 포함한 측정값, 합의 기준과의 차이 | 시험 기록 번호, 시편 보관 위치, 검토 결정 |

관찰란을 단순히 «양호»로 끝내지 마세요. 무엇을 살폈으며 어떤 기준으로 판단했는지 기록합니다. 허니컴 단면만 검사했다면 검사 범위를 명시해야 합니다. 단면 관찰만으로 모든 내부 유로의 상태를 판단할 수는 없습니다.

## 원인 판단에 앞서 변화가 처음 관찰된 단계를 찾습니다

파형 성형 후 찢어짐이 발견됐다면, 식별된 가공 전 원지와 성형 시편을 비교합니다. 후속 처리 뒤 접합 분리가 처음 발견됐다면 해당 처리 직전과 직후의 기록을 확인하세요. «처리 후 처음 관찰됨»은 관찰 사실이지만, «원지가 부적합함»은 추가 조사가 필요한 결론입니다.

재시험을 계획할 때는 어떤 질문에 답할 것인지 먼저 적습니다. 가능하면 같은 원지 식별 정보와 기록된 공정을 유지한 상태에서 계획한 변수만 바꾸고, 다른 차이가 있다면 함께 기록하세요. 여러 조건이 동시에 바뀌었다면 결과를 한 변수의 영향으로 단정하지 않습니다.

시편 전체를 촬영한 뒤 해당 부위를 확대 촬영합니다. 필요한 경우 방향과 크기 기준을 함께 표시하세요. «불량 시편» 같은 파일명에만 의존하지 말고 시편 옆에 번호를 놓습니다. 이후 비교가 가능하도록 합의된 취급 절차에 따라 시편을 보관합니다.

## 복사해서 사용할 시험 기록 양식

시험마다 기본 정보를 한 번 작성하고, 작업 단계마다 단계 기록을 반복해서 작성하세요. 아래 빈칸은 입력용이며 예시 시험 결과가 아닙니다.

```text
시험 기본 정보
프로젝트 / 시험 번호 / 날짜 / 작업자:
이번 시험으로 확인할 질문:
원지 제품 번호 / 공급자 로트 / 롤 번호:
평면층 원지 번호 / 파형층 원지 번호:
채취 위치와 원지 방향:
공정 경로 및 개정 번호:
합격 기준 문서 / 방법 / 개정 번호:

단계 기록 — 작업마다 작성
시편 번호 / 공정 단계 / 날짜:
장비·공구 번호 / 조건 개정 번호:
처리·코팅·접합 시스템 번호(해당 시):
관찰 / 측정값 / 단위 / 방법:
변화가 처음 관찰된 단계:
사진 번호 / 보관 시편 위치:

최종 검토
확인한 요구사항 / 미해결 항목:
승인 범위(해당 시) / 결정자 / 날짜:
```

«시험 계속»은 합의된 다음 시험 단계로 진행한다는 뜻입니다. 양산 승인을 의미하지 않습니다.

## 시편 시험에서 자주 묻는 질문

### 처리 전 원지의 액체 흡수 결과로 제습 성능을 판단할 수 있나요?

아니요. 원지 또는 처리 단계의 관찰 결과로 기록해야 합니다. 완성 로터는 전체 설계와 흡착제 시스템을 대상으로 평가합니다. Munters의 [로터 개발 소개](https://www.munters.com/en-us/news-media/stories/2024/reinventing-the-wheel/)도 흡착제, 섬유, 생산 방법, 매체 형상을 각각 다룹니다. 원지 단계의 관찰은 합의된 완성 로터 시험을 대신할 수 없습니다.

### 허니컴 시편 하나가 합격하면 모든 원지 등급을 승인할 수 있나요?

판정 범위는 실제 평가한 재료, 공정 버전, 시험 조건으로 한정해야 합니다. 다른 원지 등급이나 변경된 공정에 대해 추가로 필요한 검증을 기록하세요. 시편 하나의 결과만으로 생산 일관성이 입증되는 것도 아닙니다.

### 공급자에게 시험 검토를 요청할 때 무엇을 보내야 하나요?

원지와 시편 번호, 실제 공정 순서, 버전 정보, 전후 관찰 결과, 사진, 확인하려는 질문을 전달하세요. 아직 모르는 정보는 미확인 상태로 표시합니다. 독자적인 공정 세부사항은 공급자와 합의한 채널을 통해 공유하세요.
